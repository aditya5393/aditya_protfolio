## 🌍 Deploy

<details>
<summary>🟢 <b>GitHub Pages</b> (best for your GitHub bio)</summary>

1. Create a public repo named **`aditya5393.github.io`**
2. Upload `index.html`, `css/` and `js/` at the top level
3. **Settings → Pages →** branch `main`, folder `/ (root)` → Save
4. Wait 1–2 minutes: 🎉 `https://aditya5393.github.io`
5. Paste the link into **Edit profile → Website**

</details>

<details>
<summary>⚡ <b>Netlify Drop</b> (fastest, no Git)</summary>

Open `app.netlify.com/drop` and drag the whole folder in. You get a live link in seconds.

</details>

<details>
<summary>▲ <b>Vercel</b></summary>

Import the repo at vercel.com, choose **Other** as the framework, then **Deploy**. Every push redeploys it.

</details>
